# Contributing

## Workflow

1. Создать ветку от `main`
2. Реализовать изменения с тестами
3. Запустить локально (`bash scripts/start-docs.sh` для документации)
4. PR → docs-gate автоматически проверит наличие ADR / docstrings / changelog
5. После PASS — merge
